# 🐱🌸 Котико-проект на R

Интерактивное приложение на **R + Shiny** с тремя разделами задач.

## 📋 Возможности

### 🧮 Математические задачи
- Квадратное уравнение (с вводом a, b, c)
- Факториал числа
- Поиск простых чисел до N

### 📊 Анализ данных / Статистика
- Описательные статистики (среднее, медиана, дисперсия, размах)
- Гистограмма с настройкой параметров распределения
- Корреляция Пирсона двух наборов данных

### 💰 Финансовые задачи
- Сложный процент
- Расчёт ипотеки (аннуитетные платежи)
- Дисконтирование будущей стоимости

## 🛠 Технологии

- **R** — язык программирования
- **Shiny** — фреймворк для веб-приложений
- **bslib** — современные темы Bootstrap
- **ggplot2** — графики

1. Установи R и RStudio
