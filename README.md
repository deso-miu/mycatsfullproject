## 📂 Версии приложения

В репозитории живут три версии — выбирай по настроению 💫

| Файл | Оформление | Для кого |
|------|-----------|----------|
| 💙 `app_mascot.R` | Голубое «горное утро», маскот университета, снежинки и сердечки | Для презентации и сдачи ✨ |
| 🐱 `app.R` | Яркое, с котиками и цветочками | Для души и настроения |
| 💼 `app_official.R` | Деловое, в строгом стиле | Для строгой подачи |

---

## ✨ Что умеет приложение

### 🧮 Математические задачи
- 🌷 Решение квадратных уравнений (с анализом дискриминанта)
- 🐾 Вычисление факториала
- 🌼 Поиск простых чисел в заданном диапазоне

### 📊 Анализ данных и статистика
- 🌸 Описательные статистики: среднее, медиана, дисперсия, стандартное отклонение, размах
- 🐱 Построение гистограммы распределения
- 🌺 Корреляционный анализ (коэффициент Пирсона)

### 💰 Финансовые расчёты
- 🪙 Сложный процент
- 🏠 Аннуитетный платёж (ипотека)
- 📉 Дисконтирование будущей стоимости

---

## 🛠 Технологии

- 💻 **R** — язык программирования
- ✨ **Shiny** — фреймворк для интерактивных приложений
- 🎨 **bslib** — современные темы Bootstrap 5
- 🌟 **bsicons** — иконки
- 📈 **ggplot2** — графики

---

## 🚀 Как запустить

1. Установи **R** и **RStudio** 🐱
2. Установи пакеты одной командой:
   ```r
   install.packages(c("shiny", "ggplot2", "bslib", "bsicons"))
